# Lab 1: Variables and Functions

## Reflection Questions

### 1\. How did you approach creating more flexible functions with parameters?

I made my functions more flexible by using parameters. This lets me pass different values into the function each time I use it. Instead of writing new code for every situation, I can reuse the same function with different inputs.

### 2\. What challenges did you face while incorporating conditional logic in your functions?

The main challenge was making sure my conditions covered all possible cases. I had to think about what should happen when the input was missing or invalid and make sure the function returned the correct message.

### 3\. How does refactoring improve the readability and maintainability of your code?

Refactoring helps make my code cleaner and easier to understand. It also makes it easier to fix or update later because the code is more organized. This saves time and makes the code easier to reuse.
